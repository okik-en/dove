# 某S氏の過去問まとめ

## Installation

### リポジトリのクローン

（gitのインストールは済んだものとします）

```bash
git clone https://github.com/okik-en/dove.git
cd dove
git submodule add https://github.com/okik-en/typ.git
```

### プレコミットの追加

> [!NOTE]
> [pre-commit](https://pre-commit.com/)のインストール方法:
> ```bash
> pip install pre-commit
> ```

```bash
pre-commit install
```
