6.6.アームストロングの公理系#

出題：小テスト教科書：pp. 81 - 84

アームストロング公理系は、リレーショナルデータベースの設計や理論において重要な役割を果たす。 特に、関係データベースにおける(1)を体系的に導出するための公理系として知られています。 この公理系は、データの正規化やスキーマ設計の際に、(1)の(2)を行うために使われ、冗長なデータや不整合を防ぐのに役立つ。 これは3つの基本公理から成り立っている。

  1. 3つの公理を列挙せよ。
  2. 表 2にある証明とは、何の何に対する証明を与えているのか、説明せよ。
  3. アームストロング公理系が必要/重要となる正規化はどのレベルか（第一～第三正規形、それともボイス・コッド）？ 理由と共に与えよ。
  4. 第3正規形であるが、ボイス・コッド正規形ではない、事例を1つ与えて、この事実も説明せよ。
