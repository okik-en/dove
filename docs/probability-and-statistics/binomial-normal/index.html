4.8. 標準正規分布の利用

  4. 得点の上位20%に入るための最低点を求めなさい。
解答

  2. ここで確率は割合と換言できて、すなわち試験𝐸の受験者から無作為に1人を選んだ時にその人の得点が80点以上となる確率、すなわち試験𝐸の受験者のうち得点が80点以上の人の割合を表す。

  4. 上位20%に入るということは、下位80%に属さないことを意味する。 よってその最低点を𝜑とおくと𝑃(𝑋≤𝜑)=0.80が成り立つ。 ここで𝑃(𝑋≤𝜑)=𝑃(𝑍≤𝜑−𝜇𝜎)=Φ(𝜑−𝜇𝜎)であることに注意。 標準正規分布表を利用することでΦ(0.84)≈0.7955≒0.80がいえて、Φ(𝜑−𝜇𝜎)≈Φ(0.84)である。 したがって𝜑−𝜇𝜎≈0.84であり、整理して𝜑≈𝜇+0.84𝜎=66.31+0.84×23.55=86.0920≈86を得る。ゆえに求めるべき最低点は86点とわかる。
